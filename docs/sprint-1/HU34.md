HU34 - Asignar roles a usuarios
Backend
#	Tarea	Descripción
T1	Modelo de roles	Agregar campo role al usuario (ej. admin, user) usando Django Groups o campo directo en un perfil/modelo extendido
T2	Endpoint asignar rol	PATCH /api/auth/users/<id>/role/ — solo accesible por admin, cambia el rol de un usuario
T3	Incluir rol en login	Modificar el endpoint /api/auth/login/ (HU35-T2) para devolver el role del usuario en la respuesta
Frontend
#	Tarea	Descripción
T4	Vista gestión de usuarios	Tabla con usuarios y selector de rol, consume el endpoint PATCH
T5	Guard de roles	RoleGuard que protege rutas según el rol almacenado en el token/storage
